### 🐜 Ant Colony Optimization

A Python implementation of an **Ant Colony Optimization (ACO)** algorithm for solving a small route-optimization problem.

The algorithm simulates multiple ants selecting paths between cities using:

- Pheromone levels
- Distance-based heuristic information
- Probabilistic path selection
- Pheromone evaporation
- Iterative optimization

The program tracks and reports the best route, total distance, and iteration in which the best solution was discovered.

[View Ant Colony Optimization](ACO.py)

## Running a Project

Clone the repository:

```bash
git clone https://github.com/joeyfarruggia/python-projects.git
cd python-projects
```

Most of the smaller exercises can be run directly:

```bash
python filename.py
```

Some projects require additional Python packages.

For example, Escape From Dino Island uses:

```bash
pip install colorama
```

Ant Colony Optimization uses:

```bash
pip install numpy
```

Other AI and data projects may require additional dependencies depending on the project.
